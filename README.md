# Dolar-Kuru-Veri-Analizi
Türkiye'de dolar kurunun zaman içindeki değişiminin pyhton ile analizi
## Proje Hakkında

Bu projede Türkiye'de dolar kurunun zaman içerisindeki değişimi Python kullanılarak incelenmiştir. Veriler üzerinden doğrusal regresyon analizi gerçekleştirilmiştir.

## Kullanılan Teknolojiler
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Genel Analiz

- Dolar kurunun zamana bağlı değişimi incelenmiştir.
- Gerçek değerler ve regresyon doğrusu grafik üzerinde gösterilmiştir.
- Sabit katsayı ve eğim katsayısı hesaplanmıştır.
- Modelin açıklama gücü R² değeri ile değerlendirilmiştir.

## Ekonomik Değerlendirme

Analiz sonucunda dolar kurunun incelenen dönemde zamanla pozitif yönlü bir eğilim gösterdiği görülmüştür. Eğim katsayısı, zaman ile dolar kuru arasındaki ortalama değişim ilişkisini göstermektedir.

R² değeri ise dolar kurundaki değişimin ne kadarının zaman değişkeniyle açıklandığını ifade etmektedir.

## Proje Durumu

İlk aşama tamamlanmıştır. İlerleyen aşamalarda altın ve Borsa İstanbul verileri de analize dahil edilerek çalışma genişletilecektir.
